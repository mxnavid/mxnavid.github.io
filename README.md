# mxnavid.com

Personal portfolio site — single-page, static HTML/CSS/JS, no build step. Hosted on GitHub Pages at [mxnavid.com](https://mxnavid.com).

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in a browser.

## Structure

- `index.html` — all page content/sections
- `css/style.css` — styles, theme, responsive layout
- `js/main.js` — scroll fade-ins, active-nav highlighting, mobile nav toggle
- `assets/resume/` — resume PDF
- `CNAME` — custom domain config for GitHub Pages
